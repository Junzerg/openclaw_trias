# Phase 3 · 像素演播厅前端 (Pixel Art Frontend)

> **目标**：PRD 中的核心高光 — 将 Agent 行为映射为 8-bit 像素动画。
> **前置依赖**：Phase 2（WebSocket 事件流可用）
> **预估复杂度**：⭐⭐⭐⭐ 高
> **优先级**：🟡 并行 — 美术资源和渲染可与 Phase 2 并行准备
> **建议拆分**：工程基础 → 美术资源 → 议会场景 → 行政场景 → 法院场景

---

## 3.1 工程基础

| 序号 | 工作项 | 说明 |
|------|--------|------|
| 3.1.1 | **前端项目搭建** | Vite + React (TypeScript)；集成 Phaser.js 或 PixiJS 作为 2D 渲染引擎 |
| 3.1.2 | **WebSocket 客户端** | 连接 Phase 2 的 `/ws/task/{id}`，事件解析 → 渲染指令分发 |
| 3.1.3 | **场景管理器** | 三大场景 (议会/行政/法院) 自动切换引擎，根据法案生命周期状态决定当前激活场景 |
| 3.1.4 | **事件-动画映射引擎** | 将 PRD §4 的 9 种 WebSocket 事件映射为具体的 Sprite 动画指令 |

## 3.2 场景实现

### 3.2.1 🏛️ 议会大厅 (The Parliament)

**视觉布局**：左右对立的阶梯状议席，中央为演讲台。

| 动画 | 触发事件 | 视觉效果 |
|------|---------|---------|
| **提案** | `propose` | 信使送信入厅 → 议员上台展开卷轴 → 头顶气泡打字机效果 |
| **Lv1 辩论** | `propose` (多轮) | 座位上小人交替冒出文字气泡（如 "这会导致内存泄漏！"）|
| **Lv2 激烈冲突** | `brawl` (intensity > 5) | 小人脸红，离席靠近，互扔像素纸团/皮鞋/咖啡杯（抛物线物理），爆出 🤬💢 |
| **Lv3 议长控场** | `order` | 屏幕微震，议长疯狂敲法槌，8-bit `咚咚咚` 音效 + 巨大 `ORDER!` 飘字 |
| **表决通过** | `vote_passed` | 议长一锤定音，全场亮绿灯，卷轴经传送带发往白宫 |

### 3.2.2 🏢 行政格子间 (The Oval Office & Bureaucracy)

**视觉布局**：横向卷轴的总统办公室与下属格子间。

| 动画 | 触发事件 | 视觉效果 |
|------|---------|---------|
| **签署法案** | `sign_act` | 总统拿起羽毛笔签字，绿色 `APPROVED` 盖章特效 |
| **否决法案** | `veto` | 总统甩出红色 `VETO` 盖章，法案卷轴弹回议会 |
| **执行任务** | `tool_call` | 部长疯狂敲键盘，屏幕闪烁代码流 |
| **执行报错** | `tool_call` (error) | 小人头上冒黑烟 💨 |

### 3.2.3 ⚖️ 最高法院 (The Supreme Court)

**视觉布局**：全黑背景，聚光灯打在高高在上的像素大法官身上。

| 动画 | 触发事件 | 视觉效果 |
|------|---------|---------|
| **合宪通过** | `constitutional` | 法官高举法槌落下，闪烁绿光，浮现 `CONSTITUTIONAL`，成果打包发出 |
| **违宪驳回** | `unconstitutional` | 屏幕剧烈震动，红光警报，法槌重砸，红色 `UNCONSTITUTIONAL` 印章，卷轴碎裂燃烧 |

## 技术选型对比

| 引擎 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **Phaser.js** | 成熟的 2D 游戏引擎，物理引擎内置，社区大 | 较重，学习曲线稍陡 | ⭐⭐⭐⭐ |
| **PixiJS** | 轻量高性能渲染器，适合非游戏场景 | 无内置物理引擎，需自己写 | ⭐⭐⭐ |
| **React-Canvas** | React 生态内，简单 | 功能有限，不适合复杂动画 | ⭐⭐ |

> 建议选用 **Phaser.js**：内置物理引擎适合抛物线投掷计算，Tilemap 支持好，社区丰富。
