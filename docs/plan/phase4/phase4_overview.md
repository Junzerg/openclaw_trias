# Phase 4 · 集成、端到端串联 & UX 优化

> **前置依赖**：Phase 1 + Phase 2 + Phase 3（三层基本就绪）
> **预估复杂度**：⭐⭐⭐ 中高
> **优先级**：🟢 后续

## 4.1 端到端集成测试

| 序号 | 工作项 | 说明 |
|------|--------|------|
| 4.1.1 | **全链路冒烟测试** | 完整 Petition → 辩论 → 表决 → 签署/否决 → 执行 → 审判 → 前端动画 |

## 4.6 错误处理 & 重试

| 序号 | 工作项 | 说明 |
|------|--------|------|
| 4.6.1 | **LLM 超时/限流** | 自动重试 + 指数退避 + 用户通知 |
| 4.6.2 | **Skill 执行失败** | 错误上报行政分支 → 判断是否需要 Veto |
| 4.6.3 | **Veto 重入循环** | 设置最大 Veto 次数防死循环 |
| 4.6.4 | **违宪重做上限** | 设置最大重做次数，超过后降级为人工处理 |
| 4.6.5 | **WebSocket 断线重连** | 前端自动重连 + 事件补发 |
