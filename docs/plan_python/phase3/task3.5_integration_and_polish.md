# Phase 3 Task 3-E: 音效集成与端到端联调

## 任务目标
为渲染出来的动画赋予复古的 8-bit / 16-bit 音效灵魂，并完成从命令行下发任务到前端浏览器像素播客全闭环呈现的最终测试。

## 具体执行步骤
1. **音效组件开发与挂载 (Audio Engine)**
   - 使用 Phaser 自带的 WebAudio API 播放 `public/assets/sfx/` 下音频。
   - 统一建立全局 `SoundManager`，暴露出类似 `SoundManager.play('gavel')`, `.play('typewriter')`, `.play('throw_hit')` 接口供上层使用。
   - 在各场景的动画帧回调事件（如碰到物体事件、文字打出事件记录）中嵌入这些播放行为。
2. **端到端流程验证 (End-to-End Visual QA)**
   - **联调环境建立**：开启 `run_server.py`，启动 Vite dev server。
   - 发出普通请求：确认一整套顺滑通关的绿灯动画不发生任何断层。
   - 发出引发争议请求：验证吵架场景强度阈值的真实感表现。
   - 发出危险命令请愿（如让工程部长操作 `rm -rf`）：验证大法官拔出违宪法槌，一锤定音并中断画面，并返回重试的环路。
3. **细节打磨层**
   - 摄像机抖动强度配比（不要让眼睛太困顿）。
   - 适配移动端或非 16:9 画幅的情况，确保 8-bit 颗粒度无论缩放都不会糊掉 (Scale mode `FIT/NEAREST`)。
   - 防抖：确保高并发或后端迅速返回的 WS 消息队列得到了有效的防抖和序列播放，防止瞬间涌入导致动画堆积。

## 验收标准
- [x] 音画同步良好，投掷物命中带有打击声。
- [x] 打出来的文本具有极度舒适的打字机音效搭配。
- [x] `run_server.py` 和网页结合在一起构成了整个 OpenClaw 闭环演示站功能。
