# Phase 3: Character Sprite Sheet Generation Prompts

**使用方法**: 所有的角色我们都要求 AI 输出“三连帧格式”(Sprite Sheet)，以便在 Phaser 中直接裁剪。

**关键约束**: 复制给 AI 时请强调：**“必须在纯色/透明背景上绘制，保持严格的横排 3 帧格式，绝不带有任何 3D 渲染效果”**。

## 1. 议长 (The Speaker)
```text
Perfectly pixelated 16-bit SNES classic RPG style character sprite sheet of an older, dignified parliament speaker wearing elegant neutral-toned formal robes. Flat side-view layout against a solid transparent backdrop. Arranged in a tidy horizontal row of exactly 3 equal-sized frames. Left frame: idle standing pose. Middle frame: pointing authoritatively. Right frame: banging a large wooden gavel. Distinct sharp pixel art, consistent character design, flat shading, video game asset.
```
