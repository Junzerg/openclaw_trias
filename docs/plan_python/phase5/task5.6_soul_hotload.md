# Phase 5 - Task 5-F: SOUL.md 在线编辑与热重载

> **前置依赖**: 前后端基础设施基本就绪
> **包含项**: 5.7
> **模块特性**: 产品增值级全栈功能

## 📌 目标
在高度自治的沙盒之外，给上帝视角的用户保留最终的政策干预扳手：**The SOUL Engine** (智能体底层人设引擎)。用户能够通过前端直观改写各职位 Agent 的系统设定位（System Prompt）以调节宏观政治生态倾向，并且无缝热替换。

## 📋 涵盖子项
- **5.7.1 在线 SOUL 编辑器**: 游戏前端提供的 Markdown 编辑控制台。
- **5.7.2 热更新机制**: Agent 后端在轮询中读取并注入新配置，且不要求终端重启。
- **5.7.3 面板预设人设库**: 一键“温和化”、“极端化”、“效率至上化”的大清洗套餐。

## 🛠️ 实现建议
- **前端编辑面板**: 集成成熟好用的代码高亮文本框（例如 `@uiw/react-textarea-code-editor` 等中轻量级组件）。在 Header 加入一个闪烁的 “SOUL CONFIG” 干预入口。预设模板放在静态文件中供下拉取用。
- **后端热载通道**: 各 Agent 不应把人设锁在进程加载初期的僵死常数内，而是须提供如 `Agent.inject_soul(text)` 的能力，或者在获取 prompt() 返回时去抓取内存或持久化存储的最鲜文件流，从而完成替换。

## 验收标准
- [ ] 前端带有华丽（或赛博硬核风格）的人设大盘操控板，支持直接改写每个政客的性格文件。
- [ ] 选定【激进派】模板快速注入并 Save 的操作，可以在随后发生的新一轮请愿辩论中产生极其鲜明的口吻和反击差异。
- [ ] 重启后端应用后，之前热插拔录入的信息能持久化保存（或回档默认），需建立管理机制保证不随易丢失。
